# 🛡️ NetGuard

A browser-based self-assessment tool that helps everyday users check the security of their home or small-office Wi-Fi setup.

Users answer a short series of yes/no questions about their network. Based on their answers, the system calculates a simple risk score (Low / Medium / High) and provides a checklist of clear, actionable fixes for anything flagged.

## ✨ Features

- **10-Question Wi-Fi Security Assessment** — Simple yes/no questions about your network setup
- **Risk Score Calculation** — Automatically determines Low, Medium, or High risk
- **Personalized Checklist** — Get specific fixes for anything flagged
- **Save Your Progress** — Answers are saved locally with `localStorage`
- **Reset Button** — Clear all answers and start over
- **Contact Form** — Send questions to the NetGuard team
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Learn More Carousel** — Browse Wi-Fi security tips
- **Active Navigation** — Highlights the current page in the menu
